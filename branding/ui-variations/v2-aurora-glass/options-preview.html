Umbra Browser Control for AI Agents Connected to 2 local sessions.

Settings

Umbra pairs this browser with a companion server running on your own machine over a loopback connection. The two pair with a shared key you create here. Nothing works until the companion server is running with the same key.

First Run

  1. Click Generate Key below, then Save And Reconnect.
  2. Click Copy Environment Line and paste that line into the environment block of your MCP client's Umbra entry, then start the companion server.
  3. Click Grant Site Access so Umbra can drive the tabs a session opens.

The status dot at the top turns green once the companion server connects.

Pairing

Paired

The environment line carries the key and the port range in one string, so the key is typed nowhere. A generated key replaces the old one: any companion server still holding the previous key stops pairing.

Connection

47821-47852

Umbra scans this port range on 127.0.0.1 for a companion server holding the same key.

Site Access

Granted

Site access granted. Sessions can drive the tabs they own.

Umbra reads and drives only the tabs a session owns, and it opens those tabs itself in a labelled group. Chrome has no way to grant that per tab, so it asks for site access once, here, instead of at install time.
