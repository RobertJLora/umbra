First Run

  1. Click Generate, then Save And Reconnect.
  2. Click Copy Line and paste it into the environment block of your MCP client's Umbra entry, then start the companion server.
  3. Open Settings below and grant site access.

Connection

The copied line carries the key and the port range together, so the key is typed nowhere. Generating a new key replaces the old one.

Checking site access...
